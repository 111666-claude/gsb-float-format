# float-format

按十进制规则格式化数值（四舍六入五成双、千分位、负零归一），只用 Go 标准库。

```
go test ./...
go run ./cmd/float-format --format 2.675 --digits 2
go run ./cmd/float-format --format 1234567.891 --digits 2 --group
```

## 口径（README 为准）

- **按十进制字符串做舍入**（不先转 float 再 `Sprintf`）：`2.675` 保留 2 位是 `2.68`，
  即使它的二进制表示是 `2.67499…`。
- **四舍六入五成双**：`--format 2.5 --digits 0` 给 `2`、`--format 3.5 --digits 0` 给 `4`、
  `0.125` 保留 2 位给 `0.12`；舍弃位恰好是 `5`（后面全为 0）时向偶数靠，
  `5` 后面还有非零位则进位。
- **千分位**：`--group` 时整数部分每三位加逗号：`1234567.891` 保留 2 位是 `1,234,567.89`；
  负数时逗号加在数字部分、负号在最前（`-1,234,567.89`）。
- **负零归一**：结果为零时不出现 `-0`：`--format -0.001 --digits 2` 给 `0.00`。
- 不变量：输出的小数位数恰好等于 `--digits`（0 到 10 都支持）；同一输入重复格式化结果相同；
  与「按十进制字符串手工舍入」的参考实现逐字符一致。
- 非数值输入报错，错误信息带原串。
- 规模：100 万次格式化线性完成，输入字符串长度 ≤ 1 万位也不退化成 O(n²)。

## 实现

- `Format` 直接在十进制字符串上逐位处理：拆分符号 / 整数 / 小数，按四舍六入五成双
  截断或进位，再按需加千分位、归一负零，全程不经过二进制浮点。
- `numfmt_test.go` 里另有一份独立编写的参考实现 `referenceFormat`（含银行家舍入表），
  测试对样例与 1 万个随机生成的数值逐字符比对两者输出。

## 参数

```
--digits N     保留几位小数（默认 2，范围 0 到 10）
--group        整数部分加千分位
```

## 输出

```
格式化后的数值
```
