# float-format

按十进制规则格式化数值（四舍六入五成双、千分位、负零归一），只用 Go 标准库。

```
go test ./...
go run ./cmd/float-format --format 2.675 --digits 2
go run ./cmd/float-format --format 1234567.891 --digits 2 --group
```

## 口径（README 为准）

- **按十进制字符串做舍入**（不转 float、不用 `Sprintf`）：逐位处理输入字符串，
  `2.675` 保留 2 位是 `2.68`，不受二进制浮点表示影响。
- **四舍六入五成双**（银行家舍入）：`--format 2.5 --digits 0` 给 `2`、`--format 3.5 --digits 0` 给 `4`、
  `0.125` 保留 2 位给 `0.12`；被丢弃部分恰为 `5` 且保留末位为奇数时才进位。
- **千分位**：`--group` 时整数部分每三位加逗号：`1234567.891` 保留 2 位是 `1,234,567.89`；
  负数时逗号只加在数字部分，负号在最前（`-1,234,567.89`）。
- **负零归一**：结果为零时不带负号，`--format -0.001 --digits 2` 给 `0.00`。
- 不变量：输出的小数位数恰好等于 `--digits`（不足补零、多余按口径舍入）；
  同一输入重复格式化结果相同；`--digits` 支持 0 到 10，超出报错。
- 非数值输入报错，错误信息带原始输入串。
- 规模：100 万次格式化线性完成，输入字符串长度 ≤ 1 万位不退化成 O(n²)。
- 对照：`numfmt_reference_test.go` 里有独立的手工十进制舍入参考实现（含银行家舍入表），
  测试对样例与随机生成的 1 万个数值逐字符比对两者输出。

## 参数

```
--format S     要格式化的十进制字符串（必填）
--digits N     保留几位小数（默认 2，范围 0 到 10）
--group        整数部分加千分位
```

## 输出

```
格式化后的数值
```
